Fonts for the share cards (components/public/og/card.tsx). next/og needs TTF, so these are
static TrueType instances, subset to Basic Latin and Latin-1 (U+0020-007E, U+00A0-00FF):

  SourceSerif4-Semibold.ttf             Source Serif 4, weight 600, optical size 60
  AtkinsonHyperlegibleNext-Regular.ttf  Atkinson Hyperlegible Next, weight 400
  AtkinsonHyperlegibleNext-Bold.ttf     Atkinson Hyperlegible Next, weight 700

Downloaded from the Google Fonts css2 API with a text= subset. Both families are under the SIL
Open Font License 1.1; the license texts are OFL-SourceSerif4.txt and OFL-AtkinsonHyperlegibleNext.txt.
