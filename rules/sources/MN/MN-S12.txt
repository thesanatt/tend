Application Instructions
 Complete separate applications for each victim
 A guardian or relative should file on behalf of a minor,
incapacitated, or deceased victim
 Apply as soon as possible. Additional expenses can be added later.
 Apply even if no current out-of-pocket expenses. Can re-open
claim if incur expenses in the future.

Application Instructions, Cont.
• Apply using VSP or paper application
• Fill out as completely as possible. If information is unknown, ok
to leave blank.
• Submit /upload copies of bills, receipts and insurance EOBs if
available
• A mileage form will be sent to claimant after receipt of
application. Or, it is available on the OJP website.
